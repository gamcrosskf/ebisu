Le serveur Ebisu

Tout installer d'un double clic

Pour Windows et le launcher officiel : Fabric, un profil « Ebisu » avec son propre dossier, et exactement les mods du serveur, chacun vérifié. Votre Minecraft habituel n'est pas touché. Relancez-le à chaque nouvelle version.

Installateur .exeLe même, en .bat

Windows peut afficher « Windows a protégé votre ordinateur » : l'installateur n'est pas signé. Cliquez sur Informations complémentaires, puis Exécuter quand même. Le launcher doit être fermé.

Installer en trois étapes

  1. 01

    Fabric

    Installez Fabric Loader pour Minecraft 26.3, puis Fabric API.

  2. 02

    Le mod

    Déposez le fichier ebisu-1.0.27.jar dans le dossier mods de votre jeu.

  3. 03

    Jouer

    Lancez le profil Fabric. À la première connexion, la roue vous donne votre totem.
