Dernière version : 0.1.0-beta

Publiée le 9 octobre 2026

  • Minecraft 26.3
  • Fabric Loader 0.19.5+
  • Fabric API
  • Java 25
⬇ Télécharger Ebisu 0.1.0-beta (fichier JAR, 11,3 Mo)ebisu-0.1.0-beta.jar · 11,3 Mo

Version bêta : sauvegardez vos mondes avant de l'installer. Un souci, une idée ? Envoyez un ticket.

?Installer Ebisu

  1. Fabric Loader pour Minecraft 26.3 : l'installateur Fabric (nouvelle fenêtre).
  2. Fabric API, dans le dossier mods : Fabric API sur Modrinth (nouvelle fenêtre).
  3. Le .jar d'Ebisu, dans le même dossier mods (%appdata%\.minecraft\mods sous Windows).
  4. Lancez le jeu avec le profil Fabric. Le Codex s'ouvre en jeu avec la touche K.
