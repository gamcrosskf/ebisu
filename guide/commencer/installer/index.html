Installer & jouer en ligne

Deux façons d'installer Ebisu : l'installateur du serveur, qui prépare tout d'un double clic, ou l'installation à la main, en trois fichiers.

✦ L'essentiel

  • Pour le serveur Ebisu : téléchargez l’installateur et lancez-le. Il crée un profil « Ebisu » dans le launcher officiel, avec exactement les mods du serveur.
  • À la main : Fabric Loader, Fabric API et le .jar d’Ebisu dans le dossier mods. Java 25.
  • Pour mettre à jour, relancez l’installateur, ou remplacez le .jar par celui de la dernière version.
  • L’adresse du serveur vous est donnée par son hôte : elle n’est pas publiée ici.

L’installateur du serveur

Pour Windows et le launcher officiel de Minecraft. Il installe Fabric, crée un profil Ebisu avec son propre dossier de jeu (%APPDATA%\.minecraft-ebisu), et y dépose les mods du serveur, chacun vérifié par sa somme SHA-256. Votre Minecraft habituel n’est pas touché.

  1. Téléchargez Installer-Ebisu.exe (ou le même en .bat).
  2. Lancez-le d’un double clic. Une fenêtre suit chaque étape. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires, puis Exécuter quand même : l’installateur n’est pas signé.
  3. Ouvrez le launcher : choisissez le profil Ebisu, puis rejoignez le serveur avec l’adresse que l’hôte vous a donnée.

Pour mettre à jour

Relancez simplement l’installateur après chaque nouvelle version. Ce que le pack a retiré est enlevé ; les mods que vous avez ajoutés vous-même sont laissés. Si le pack demande un installateur plus récent, il se met à jour tout seul.

L’installation à la main

Pour jouer en solo, ou avec un autre launcher.

Minecraft
26.3
Fabric Loader
0.20.1+
Java
25
  1. Fabric Loader pour Minecraft 26.3 : avec l’installateur Fabric.
  2. Fabric API, dans le dossier mods : sur Modrinth.
  3. Le .jar d’Ebisu, dans le même dossier mods (%appdata%\.minecraft\mods sous Windows) : Télécharger.

Lancez le jeu avec le profil Fabric. À la première connexion, la roue vous donne votre totem : voir Premiers pas.

Avant une mise à jour

Sauvegardez vos mondes avant chaque mise à jour.

Avec des shaders

L’Astrelume est un monde sans jour : certains packs de shaders l’éclairent comme un jour ordinaire. La commande /ebisushaders règle votre pack pour qu’elle reste sombre, et /ebisushaders restore revient à l’original. Le jeu vous le propose dans le chat à votre première arrivée. Le détail est dans L’Astrelume.
